# Publish this GitHub profile README

1. On GitHub, create a new **public** repository named exactly `TinyyRick`.
2. Download this folder's `README.md` and `.github/workflows/snake.yml` into that repository, preserving the directories.
3. Commit and push to the `main` branch.
4. Go to **Actions**, open **Generate contribution snake**, and choose **Run workflow** once. The `output` branch and animated SVGs will be created automatically.

GitHub will then show the README at the top of https://github.com/TinyyRick.
